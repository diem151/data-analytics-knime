# data-analytics-knime
An exploratory data analysis project investigating chocolate ratings, cocoa content, bean types, origins, companies, and company locations. The workflow includes data cleaning, missing-value handling, data transformation, aggregation, rating classification, and interactive data visualization using KNIME.
# Objectives
- Analyze chocolate ratings
- Identify highly rated companies and bean origins
- Explore cocoa percentage distribution
- Analyze rating trends over time
- Investigate the relationship between cocoa percentage and ratings
- Create meaningful data visualizations
# Data Preparation
- Missing-value handling
- Column renaming
- String manipulation
- Cocoa percentage conversion
- Bean-type processing
- Data aggregation
# Analysis & Visualization
- Top-rated companies
- Lowest-rated companies
- Bean origins
- Company locations
- Cocoa percentage distribution
- Rating trends over time
- Cocoa percentage vs. rating
- Rating categories
